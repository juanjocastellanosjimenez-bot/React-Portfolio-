# React Portfolio (COMP229 Assignment 1)

Personal portfolio with Home, About, Projects, Education, Services and Contact pages.

## Run locally
    npm install
    npm run dev

## Structure
- `src/data.js`: all your content (edit the [bracketed] values)
- `src/pages/`: one file per page
- `src/components/`: Navbar, Logo (SVG), Img (image with fallback)
- `public/images/`: your photos (see README.txt inside)
- `public/resume/`: your resume PDF

## Deploy
Push to GitHub, then import the repo in Vercel or Netlify (build command `npm run build`, output `dist`).
